LEVEL 1 · about 2 months

Foundation

Complements, doubling, and quick addition and subtraction
By the end: Take any number from 100, 1000 or 10000 instantly. Add and subtract two-digit numbers mentally. Double and halve with confidence.

Taking any number away from 100, 1000 or 10000

All from 9, and the last from 10
Nikhilam Navatashcaramam Dashatah
When a child can use it
Whenever you subtract from a base — 100, 1000, 10000. Every digit except the last comes off 9; the last comes off 10.
When they should not
Not for ordinary subtraction like 47 − 23, where neither number is a base.
How it is taught
1000 − 357 9 − 3 = 6 9 − 5 = 4 10 − 7 = 3 Answer 643
Works well on
1000 - 357 = 643
100 - 68 = 32
10000 - 4271 = 5729
1000 - 909 = 91
Should not be used on
47 - 23
856 - 341
Common mistake
Taking the last digit from 9 as well, giving 642 instead of 643.
Rule for the app: The number being subtracted must have no more digits than the base, and must not end in 0 at first — trailing zeros need a different handling and confuse a beginner.

Finding the complement — what a number needs to reach the next ten or hundred

Friends / Param Mitra
Purana-Apuranabhyam
When a child can use it
Any single or two-digit number, finding what it needs to make 10, 100 or 1000.
When they should not
Not needed once a child adds fluently without thinking in complements.
How it is taught
What does 68 need to make 100? All from 9, last from 10: 3 and 2 → 32
Works well on
68 → 100 = 32
7 → 10 = 3
450 → 1000 = 550
Common mistake
Forgetting that a number ending in 0 takes its last digit from 10 as well, so 450 → 550 not 560.
Rule for the app: Complements are the foundation of everything later. A child should be quick at this before any multiplication method is introduced.

Doubling and halving any number

Doubling
Anurupyena (proportionately)
When a child can use it
Any number. Doubling repeatedly gives ×4 and ×8; halving gives ÷2, ÷4.
When they should not
Halving an odd number introduces a half, which should wait until decimals.
How it is taught
Double 47 Double the tens: 80 Double the units: 14 80 + 14 = 94
Works well on
double 47 = 94
double 268 = 536
half of 86 = 43
Should not be used on
half of 47
Common mistake
Doubling the digits separately and writing 814 instead of carrying.
Rule for the app: Only give even numbers for halving at this level.

Adding and subtracting by completing to a ten

Split and merge
Ekadhikena Purvena (by one more than the one before)
When a child can use it
Adding a number close to a ten or hundred — add the round number, then adjust.
When they should not
Not worth it when both numbers are already easy, like 23 + 14.
How it is taught
68 + 27 Add 30: 98 Take back 3: 95
Works well on
68 + 27 = 95
145 + 98 = 243
76 - 29 = 47
Should not be used on
23 + 14
Common mistake
Adjusting the wrong way — adding 3 back instead of taking it off.
Rule for the app: The number added should be within 3 of a ten, or the adjustment is harder than the sum.

LEVEL 2 · about 2 months

Multiplication I

The special multiplications that give an answer in one line
By the end: Multiply by 11 and 12 instantly. Square any number ending in 5. Multiply numbers near 100 without long multiplication.

Multiplying any number by 11

Add the neighbour
Sopantyadvayamantyam
When a child can use it
Any number times 11. Write the first digit, then each pair added, then the last digit.
When they should not
Not for 12 or 13 — those need a different handling.
How it is taught
35 × 11 First digit 3 3 + 5 = 8 Last digit 5 Answer 385
Works well on
35 x 11 = 385
72 x 11 = 792
68 x 11 = 748
234 x 11 = 2574
Should not be used on
35 x 12
Common mistake
Not carrying when a pair adds to more than 9 — 68 × 11 gives 748, not 6148.
Rule for the app: Start with pairs that do not carry (below 10), then introduce carrying.

Squaring any number ending in 5

One more than the one before
Ekadhikena Purvena
When a child can use it
Only numbers ending in 5, being squared. 25², 65², 115².
When they should not
Not for numbers ending in anything else, and not for two different numbers.
How it is taught
65² Take the 6, multiply by one more: 6 × 7 = 42 Write 25 after it Answer 4225
Works well on
25 x 25 = 625
65 x 65 = 4225
95 x 95 = 9025
115 x 115 = 13225
Should not be used on
64 x 64
65 x 75
Common mistake
Using it for 65 × 75, where both end in 5 but they are different numbers.
Rule for the app: The number must end in 5 AND be multiplied by itself. Never generate a sum where only one condition holds.

Multiplying two numbers with the same tens digit whose units add to 10

Same first, friends after
Antyayordashake'pi
When a child can use it
43 × 47 — same tens digit, units summing to 10. Also 62 × 68, 91 × 99.
When they should not
If the tens digits differ, or the units do not add to 10.
How it is taught
43 × 47 Tens digit 4, times one more: 4 × 5 = 20 Units: 3 × 7 = 21 Answer 2021
Works well on
43 x 47 = 2021
62 x 68 = 4216
91 x 99 = 9009
24 x 26 = 624
Should not be used on
43 x 57
43 x 46
Common mistake
Writing the units product as a single digit — 91 × 99 needs 09, not 9.
Rule for the app: Both conditions must hold exactly. The right-hand part always fills two digits.

Multiplying two numbers just below 100

Base method
Nikhilam Navatashcaramam Dashatah
When a child can use it
Both numbers close to a base — 100 works best. 97 × 96, 88 × 91.
When they should not
If either number is far from the base, this is more work than long multiplication.
How it is taught
97 × 96 How far below 100: −3 and −4 Cross-subtract: 97 − 4 = 93 Multiply the differences: 3 × 4 = 12 Answer 9312
Works well on
97 x 96 = 9312
88 x 91 = 8008
98 x 97 = 9506
94 x 99 = 9306
Should not be used on
43 x 61
23 x 41
Common mistake
Not padding the right-hand side — 98 × 97 gives 06, so 9506 not 956.
Rule for the app: Both numbers must be within about 12 of the base. The right-hand part must fill as many digits as the base has zeros.

LEVEL 3 · about 2 months

Multiplication II

One method that multiplies anything at all
By the end: Multiply any two two-digit numbers in one line, and choose sensibly between the general method and the special ones.

Multiplying any two numbers, whatever they are

Vertically and crosswise
Urdhva-Tiryagbhyam
When a child can use it
Any two numbers of any size. This is the general method that always works.
When they should not
It always applies — but when a special method fits, that one is quicker.
How it is taught
23 × 41 Units: 3 × 1 = 3 Cross: (2×1) + (3×4) = 14 → write 4, carry 1 Tens: 2 × 4 = 8, plus carry 1 = 9 Answer 943
Works well on
23 x 41 = 943
36 x 74 = 2664
52 x 63 = 3276
47 x 58 = 2726
Common mistake
Losing a carry from the crosswise step.
Rule for the app: Introduce with sums that do not carry, then with one carry, then freely.

Multiplying near a base that is not a power of ten

Working base
Anurupyena
When a child can use it
Numbers near 50, 200, 250, 500 — a convenient multiple of a power of ten.
When they should not
If no convenient working base is near, use vertically and crosswise.
How it is taught
48 × 47, working base 50 Differences: −2 and −3 Cross-subtract: 48 − 3 = 45 Multiply by base ratio: 45 × 5 = 225 Differences multiplied: 2 × 3 = 06 Answer 2256
Works well on
48 x 47 = 2256
52 x 54 = 2808
203 x 204 = 41412
Should not be used on
23 x 41
Common mistake
Forgetting to multiply the left-hand part by the ratio between the working base and the power of ten.
Rule for the app: Only set sums where both numbers are within about 5 of the working base.

Choosing which method fits a sum

Which method?
When a child can use it
Any multiplication. The child looks at the numbers and decides before starting.
When they should not
—
How it is taught
Look at the numbers. Both near 100? Base method. Ends in 5 and squared? One more than before. Same tens, units make 10? That method. Otherwise vertically and crosswise.
Works well on
97 x 96 → base method
65 x 65 → ekadhikena
43 x 47 → antyayor
36 x 74 → urdhva
Common mistake
Reaching for a special method when the numbers do not fit it.
Rule for the app: This is an exercise type in its own right — a page mixing several shapes, where the child names the method before working it.

LEVEL 4 · about 2 months

Squares, cubes and bigger multiplication

Extending the general method, and squaring anything
By the end: Multiply three-digit numbers, square any two-digit number, and cube small numbers.

Multiplying three-digit and larger numbers

Vertically and crosswise, extended
Urdhva-Tiryagbhyam
When a child can use it
Any two numbers of three or more digits.
When they should not
—
How it is taught
The same crosswise pattern, with more steps: 5 for 3×3.
Works well on
123 x 456 = 56088
234 x 321 = 75114
512 x 316 = 161792
Common mistake
Missing one of the crosswise pairs in the middle steps.
Rule for the app: Only introduce after 2×2 is completely fluent.

Squaring any two-digit number

Duplex
Dwandwa Yoga
When a child can use it
Squaring any number. The duplex of a digit is its square; of two digits, twice their product.
When they should not
For numbers ending in 5, the special method is quicker.
How it is taught
43² Duplex of 3 = 9 Duplex of 43 = 2 × 4 × 3 = 24 Duplex of 4 = 16 Assemble: 16 | 24 | 9 → 1849
Works well on
43 x 43 = 1849
67 x 67 = 4489
28 x 28 = 784
Should not be used on
65 x 65
Common mistake
Forgetting to double in the middle duplex.
Rule for the app: Avoid numbers ending in 5, since the earlier method is better there and teaches the wrong instinct here.

Squaring a number near a base

Whatever the deficiency
Yavadunam Tavadunikritya Varganca Yojayet
When a child can use it
Squaring a number close to 100 or 1000. 98², 103².
When they should not
Numbers far from a base.
How it is taught
98² Deficiency −2 98 − 2 = 96 Deficiency squared: 04 Answer 9604
Works well on
98 x 98 = 9604
103 x 103 = 10609
94 x 94 = 8836
Should not be used on
43 x 43
Common mistake
Not padding the right-hand part to the width of the base.
Rule for the app: Within about 12 of the base.

Cubing a two-digit number

Cubing
Anurupyena
When a child can use it
Cubing any two-digit number, using a ratio series.
When they should not
—
How it is taught
14³ Ratio 4/1 Series: 1, 4, 16, 64 Double the middle two: 8, 32 Add and carry: 2744
Works well on
14 cubed = 2744
12 cubed = 1728
23 cubed = 12167
Common mistake
Doubling the wrong terms in the series.
Rule for the app: Keep to numbers below 30 at this level.

LEVEL 5 · about 2 months

Division

Dividing without long division
By the end: Divide by numbers near a base, and by any number using the flag method.

Dividing by a number just below a base

Base division
Nikhilam
When a child can use it
Divisors just below 10, 100, 1000 — like 8, 9, 88, 97.
When they should not
Divisors above the base, or far from it.
How it is taught
1234 ÷ 88 Complement of 88 is 12 Bring down and add: quotient 14, remainder 2
Works well on
1234 / 88 = 14 r 2
1132 / 9 = 125 r 7
11220 / 89 = 126 r 6
Should not be used on
1234 / 43
Common mistake
Using the complement wrongly when the divisor is above the base.
Rule for the app: Divisor must be below the base and within about 12 of it.

Dividing by any number using a flag digit

Straight division
Dhwajanka (on top of the flag)
When a child can use it
Any divisor. The last digit becomes the flag and the rest divides.
When they should not
—
How it is taught
2695 ÷ 32 Flag the 2, divide by 3 Subtract the cross product at each step Quotient 84, remainder 7
Works well on
2695 / 32 = 84 r 7
4321 / 21 = 205 r 16
1234 / 41 = 30 r 4
Common mistake
Forgetting to subtract the flag product before the next division.
Rule for the app: Start with two-digit divisors where the first digit divides cleanly.

Dividing when the divisor is a transposed expression

Transpose and apply
Paravartya Yojayet
When a child can use it
Divisors just above a base — 12, 13, 112.
When they should not
Divisors below the base, where Nikhilam is better.
How it is taught
1234 ÷ 12 Transpose 12 → −2 Bring down, multiply, add Quotient 102, remainder 10
Works well on
1234 / 12 = 102 r 10
2341 / 13 = 180 r 1
Should not be used on
1234 / 88
Common mistake
Using the wrong sign on the transposed digit.
Rule for the app: Divisor must be just above the base.

LEVEL 6 · about 2 months

Roots, fractions and algebra

The remaining methods, and applying them beyond arithmetic
By the end: Find square and cube roots, work with recurring decimals, and solve simple equations by Vedic methods.

Finding the square root of a perfect square

Square roots
Vilokanam / Dwandwa Yoga
When a child can use it
Perfect squares. The last digit and the digit sum narrow it to one answer.
When they should not
Not for numbers that are not perfect squares — that needs the full duplex method.
How it is taught
√1849 Pairs: 18 | 49 Largest square under 18 is 16, so first digit 4 Last digit 9 means the root ends in 3 or 7 43² = 1849, so 43
Works well on
root 1849 = 43
root 4489 = 67
root 7396 = 86
Should not be used on
root 2000
Common mistake
Choosing the wrong ending when both candidates are plausible.
Rule for the app: Only perfect squares at this level.

Finding the cube root of a perfect cube

Cube roots
Vilokanam
When a child can use it
Perfect cubes up to six digits. The last digit gives the last digit of the root directly.
When they should not
Not for numbers that are not perfect cubes.
How it is taught
∛12167 Last digit 7 → root ends in 3 First group 12 → between 2³ and 3³, so first digit 2 Answer 23
Works well on
cube root 12167 = 23
cube root 2744 = 14
cube root 39304 = 34
Common mistake
Forgetting that the last digits pair up as 2↔8 and 3↔7.
Rule for the app: Perfect cubes only.

Turning a fraction into a recurring decimal

Auxiliary fractions
Ekadhikena Purvena
When a child can use it
Denominators ending in 9 — 1/19, 1/29 — and by extension those ending in 1, 3, 7.
When they should not
Denominators that give a terminating decimal.
How it is taught
1/19 One more than 1 is 2 Divide by 2 repeatedly, carrying remainders 0.052631578947368421...
Works well on
1/19 = 0.052631578947368421
1/29 = 0.0344827586206896551724137931
Should not be used on
1/4
1/8
Common mistake
Losing track of the carried remainder over a long recurrence.
Rule for the app: Start with 1/19, where the pattern is shortest to follow.

Solving a simple equation in one line

Transpose and apply
Paravartya Yojayet
When a child can use it
Equations of the form (ax + b)/(cx + d) = e, and simple linear equations.
When they should not
Quadratics and above.
How it is taught
3x + 4 = 19 Transpose: x = (19 − 4)/3 = 5
Works well on
3x + 4 = 19 = x = 5
(x+1)/(x+3) = 1/2 = x = 1
Common mistake
Changing the sign of only one term when transposing.
Rule for the app: Only linear equations at this level.

Spotting when the answer is zero without working it out

When the total is the same
Sunyam Samyasamuccaye
When a child can use it
When a term is common to both sides, or the totals of numerator and denominator match.
When they should not
When no such symmetry exists.
How it is taught
12x + 3x = 4x + 5x has no common factor to cancel, so check the sums. Where the sums of both sides are equal, x = 0.
Works well on
(x+2)/(x+3) = (x+2)/(x+5) → x = -2
Common mistake
Applying it where the symmetry is only apparent.
Rule for the app: This is a recognition exercise, not a calculation one.
